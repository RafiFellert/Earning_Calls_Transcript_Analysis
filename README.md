Package Contents:
1. Transcripts/ Database: A curated dataset of historical S&P 500 earnings call transcripts from recent years.
2. Fetching_earning_calls_transcripts.py: A Python scraping utility enabling users to automate the collection of additional earnings call transcripts.
3. Combining_Earning_Call_Transcripts_With_Stock_Price.py: A Python data integration script that parses raw transcripts, retrieves corresponding next-day stock prices via Yahoo Finance, and consolidates the output into a single CSV file.
4. Predicting_Stock_Price_Based_On_Earning_Calls_Transcript.R: An R modeling script that evaluates and compares machine learning classification algorithms for predicting stock price movements from transcript text.
